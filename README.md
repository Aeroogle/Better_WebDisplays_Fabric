# Better_WebDisplays_Fabric

This mod is a modified Fabric version of WebDisplays made by ideal520520, supporting Minecraft 1.20.1. It is ported from the Forge WebDisplays originally created by ds58 and Lyzantra. This mod adds placeable screen blocks that render web pages powered by MCEF (Chromium Embedded Framework).

## Requirements

- Minecraft 1.20.1
- Fabric Loader + Fabric API
- MCEF (Fabric, 1.20.1)

## Building

```bash
./gradlew build
```

The built jar is written to `build/libs/`.
